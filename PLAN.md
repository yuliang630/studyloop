## 0. Frozen definition (no longer changes)

| Item | Content |
|---|---|
| What it is | A learning plugin for AI agents, running inside the conversation |
| What it does | Remember (memory), grade (mastery), retrieve (materials), advance (what next) |
| Who it is for | The author, plus anyone willing to install Python themselves |
| Platform | **Windows only for now** |
| Dependencies | Python 3.11+ (installed by the user); nothing else |
| Program vs. data | **Separated**: the pack holds code only; data lives in the course folder |
| Not doing | UI, bundled runtime, Linux/macOS, semantic search, multi-user, a fallback for people without an agent |
